## [业余编程社区为何抵制 LLM 的使用](https://blog.fogus.me/llm/born-against.html) ⭐️ 8.0/10

福格斯（Fogus）的文章探讨了业余编程社区为何抵制 LLM 生成的代码，起因是一个 GitHub 上的争议：有人质疑某份代码是从 AGPL 许可的国际象棋引擎 Reckless 派生而来。文章认为，反对的核心不是代码质量，而是对编程过程本身的热爱。 随着 LLM 编程助手日益普及，这种矛盾正在重塑开源治理、许可证执行和社区规范。GCC 等机构已通过拒绝重大 AI 生成代码的新政策，说明这场争论已从论坛讨论走向正式的项目规则。 文章提到 OSDev、LangDev 和国际象棋引擎开发等小众社区。评论者 podgietaru 指出，相关 GitHub 讨论涉及开发者“从其他引擎借鉴代码并做洗稿式改写”，认为 cd170a4 这样的改动并不能使代码摆脱派生属性，其中仍有受 AGPL 或未授权引擎代码影响的成分。
