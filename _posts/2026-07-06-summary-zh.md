一种新的 AI 导师系统在达特茅斯学院的一门课程中报告了 0.71 至 1.30 个标准差的效果量，但只有 16 名学生（11%）达到了完全参与，且研究缺乏随机化。 如果效果量真实，这个 AI 导师可能极大提升学生学习成果，但方法论上的问题——小样本、无对照组、可能的霍桑效应——限制了结果的可信度和普适性。 该系统使用 Claude Sonnet 4.6 对构建性回答题进行评分，并包含一个 RAG 聊天助手；论文的主要结果基于对参与课次和期中成绩的统计建模，而非随机试验。

**背景**: 效果量（通常以 Cohen's d 衡量）用标准差单位量化两组之间的差异。在教育研究中，样本量小的研究由于发表偏倚和统计功效较低，往往会报告更大的效果量。霍桑效应指的是因意识到被观察而产生的行为变化，这可能会夸大短期收益。

## [NES 复合视频为何抖动](https://nicole.express/2026/phase-altering-by-line.html) ⭐️ 7.0/10

NES 的复合视频输出出现抖动现象，原因是 NTSC 时序非标准，每扫描线有 227.33 个色同步周期，产生三帧重复模式。理光工程师通过'懒交织'技巧，将最后一条扫描线在 341 和 340 点之间交替，形成两帧模式。 这篇深入分析解释了一个经典游戏硬件中的常见伪影，对模拟器、FPGA 实现和信号处理爱好者具有重要参考价值。理解 PPU 的时序怪癖有助于保持 NES 游戏的准确画面输出。 抖动是由相位对齐问题引起的，色同步信号未与每条扫描线的起点对齐，导致色相误差每三帧重复一次。NES 的 PPU 每帧生成 262 条扫描线，色同步周期为非整数。

rss · Lobsters · 7月5日 23:04

**背景**: 复合视频（CVBS）将亮度、色彩和同步信号合并为一路信号。NES 的图形处理单元（PPU）生成非标准的 NTSC 信号，包含 240 条可见扫描线。NTSC 标准要求每行 227.5 个色同步周期，但 NES 因硬件限制使用 227.33 个，从而导致抖动。

一篇 LWN 文章探讨了如何使用 Prolly 树（概率平衡树）在数据库中实现版本控制，从而实现数据的高效差异比较和合并。 这种方法可能彻底改变数据管理，将类似 Git 的版本控制能力引入数据库，使得大规模协作数据编辑和历史追踪成为可能。 根据 DoltHub 文档，Prolly 树在读写上近似 B 树性能，同时允许差异计算时间与差异大小成比例，而非总数据大小。

rss · Lobsters · 7月5日 19:28

**背景**: Prolly 树是哈希一致的搜索树，结合了 B 树和 Merkle 树的特性。它们使用内容定义的块划分和滚动哈希函数，实现高效的结构比较。这使得它们适用于需要增量跟踪更改的版本控制系统。

## [系统恢复中的级联恢复循环与亚稳态](https://charap.co/metastability-in-recovery-cascading-recovery-with-a-loop/) ⭐️ 7.0/10

该文章探讨了级联恢复过程如何形成反馈回路，导致系统进入亚稳态，即系统长时间处于恢复阶段而无法完全稳定。 理解恢复过程中的亚稳态对于设计具有韧性的分布式系统至关重要，因为意外的循环可能导致长时间中断并降低可靠性。 文章可能借鉴了真实故障的模型，解释当系统参数接近亚稳态模式时，恢复时间如何急剧增加，这与近期形式化分析的结果一致。

rss · Lobsters · 7月6日 03:21

**背景**: 系统中的亚稳态是指系统并非完全稳定，而是长时间处于接近故障的状态。级联恢复循环是指恢复操作引发更多故障，形成延迟完全恢复的循环。这一概念在分布式系统和可靠性工程中非常重要，因为此类循环可能导致严重中断。

## [利用 CSS 泄漏文本节点](https://blog.pspaul.de/posts/bench-press-leaking-text-nodes-with-css/) ⭐️ 7.0/10

一名安全研究员发表了一篇文章，展示了一种利用 CSS 选择器从网页中窃取文本节点的新型技术。 这一技术揭示，通常被视为无害的样式语言 CSS 也可被用于窃取数据，对网页用户隐私构成重大威胁。 该攻击可能利用 CSS 选择器匹配特定文本模式，并通过背景图片等 CSS 功能触发 HTTP 请求，与已知的 CSS 注入攻击类似。

rss · Lobsters · 7月5日 18:40

**背景**: CSS（层叠样式表）用于控制网页的视觉呈现。CSS 注入漏洞可能允许攻击者注入恶意样式，先前的研究已经表明，CSS 可以通过属性选择器和其他技术被滥用于数据窃取。这种新方法将攻击面扩展到文本节点，文本节点常被忽视但可能包含敏感数据。
